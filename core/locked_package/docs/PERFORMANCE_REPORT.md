## 3. 训练与协议

- 数据：`反应logk指纹数据_25类_含环境无机物_Other_1626条.csv`（1626×25类）
- 划分：`固定划分_1626_同分子异pH非均分_75-12.5-12.5.json`（1240/186/200）
- 选模：`validation-only`；`DECAT_TEST_GUIDED=0`；测试仅最终揭盲
- 架构：Transformer 中心双专家 + 化学注意力 + 物理锚定 + 门控残差 + 融合套件
- 最终输出：`nn_plus_res_rf`（NN 主预测 + RF 残差校正）
- best_epoch：**33**；seed：**242**
- 超参：fp_bits=3147, topk=914, d_model=212, batch=32, lr=0.003, λ_phys=0.08, λ_inv=0.18, λ_dro=0.28
